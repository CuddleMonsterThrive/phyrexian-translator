Use the font in InDesign
  1. Press Download font (.ttf) next to the Phyrexian text and accept the save.
  2. Double-click the file and choose Install (on Mac it opens in Font Book: choose Install Font).
  3. Restart InDesign. The font is listed as Phi_horizontal_gbrsh_9.8.
  4. Copy the text here with Copy text, then paste it in InDesign with Ctrl+Shift+V (Cmd+Shift+V on Mac) and apply the font.
  5. Turn hyphenation off and set tracking to 0. Words are separated by the comma character, so avoid regular spaces.

Font: Phi_horizontal_gbrsh_9.8 by Phie (Stas.tk), under the SIL Open Font License 1.1. It works in any app that can use installed fonts.

Please read: this tool changes how English is written, it does not translate it. Sound mode spells each word by how it is pronounced, using simple spelling rules, so irregular words can come out off. Letter for letter mode swaps every English letter for its Phyrexian character, the way the printed cards do. Phyrexian vocabulary and grammar are not applied, because no complete dictionary exists. The letter tables come from the MTG Wiki's Phyrexian language page.
